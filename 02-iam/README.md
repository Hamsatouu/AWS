## TP — Gestion des identités IAM

### Objectif

Découvrir la gestion des identités et des permissions avec AWS IAM.

### Étapes réalisées

- [ ] Activation de la MFA sur le compte root.
- [ ] Création du groupe `Administrators`.
- [ ] Création du groupe `Developers`.
- [ ] Création du groupe `ReadOnly`.
- [ ] Création de l’utilisateur `admin-user`.
- [ ] Création de l’utilisateur `dev-user`.
- [ ] Création de l’utilisateur `readonly-user`.
- [ ] Création de l’utilisateur `api-user`.
- [ ] Création de la policy S3 personnalisée.
- [ ] Création de la policy EC2 limitée aux régions européennes.
- [ ] Création du rôle EC2.
- [ ] Création du rôle Lambda.
- [ ] Configuration de la password policy.
- [ ] Consultation d’Access Advisor / Last accessed.
- [ ] Création d’un IAM Access Analyzer.

### Étape mise de côté

- [ ] Rôle cross-account : non réalisé, car cette étape nécessite un deuxième compte AWS réel.
